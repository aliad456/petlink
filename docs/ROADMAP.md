# Kami — מפת דרכים ומצב נוכחי

> מסמך חי. מעדכנים אותו בסוף כל שלב. האפיון המלא ב-`docs/SPEC.md`.

## מה כבר בנוי ✅

| שלב | מצב |
|---|---|
| **1. תשתית** | הושלם: מסד נתונים, התחברות, הרשאות, 2FA למנהלים, יומן פעולות |
| **עיצוב** | הושלם: Liquid Glass, רקע ציורי חיות (סגנון וואטסאפ), header, לוגו Kami עם אנימציה, favicon ואייקון אפליקציה, מעברי עמודים, מצב כהה |
| **2. פאנל ניהול** | משתמשים ✅ · קטגוריות ופילטרים ✅ · עסקים ✅ · יומן פעולות ⏳ · מנהלים והרשאות ⏳ (נדחה לבקשת הבעלים) |
| **3. עמוד עסק** | הושלם: עמוד בסגנון פרופיל (רקע, פרופיל, בועת סטטוס, פס הישגים, פרטים, שעות, גלריה, מחירון), רישום, עורך עם תצוגה חיה, סינון מילים גסות במסד, אישור בפאנל. PRO — חלון "בקרוב" + רשימת המתנה |

## מה נשאר

| שלב | מה כולל |
|---|---|
| **2 (המשך)** | צפייה ביומן הפעולות, הוספת עובדים |
| **4. חיפוש** | לפי קטגוריה, מיקום, מרחק, והפילטרים הייחודיים (פתוח עכשיו, מגיע לבית, שבת) |
| **5. ביקורות** | כתיבה, דיווח על פוגענית, תור טיפול בפאנל |
| **6. מנויים וסליקה** | PetLink PRO ב-39.90 ₪, מסלול סטודנטים עם קוד, ספק סליקה ישראלי |
| **7. עורך AI** | עיצוב עמוד העסק, כתיבת "אודות" ומחירון בעזרת AI |
| **8. השלמות** | באנרים, ימי אימוץ, דשבורד עם נתונים והכנסות |

**סדר מומלץ:** שלב 4 (חיפוש) — אחריו אפשר להתחיל למלא את המדריך. במקביל: פיצ׳רי PRO כשהסליקה (שלב 6) מתקרבת. אחרי אלה אפשר להתחיל למלא את המדריך.


## לפני ההשקה
- שירות מייל (SMTP, למשל Resend), כדי שמיילי אישור ואיפוס יגיעו לכל משתמש. אחר כך לעדכן את תבניות המייל לקישורי `token_hash` (ראו `src/app/auth/callback/route.ts`).
- תנאי שימוש ומדיניות פרטיות, וקישור אליהם בטופס ההרשמה.
- בחירת דומיין ל-Kami וחיבורו (ואז לעדכן `NEXT_PUBLIC_SITE_URL`).

## החלטות

| נושא | החלטה |
|---|---|
| שם ומיתוג | **Kami** (לשעבר PetLink). לוגו: K עם טבעת זוהרת, שנפתח ל-"Kami" במעבר עכבר. הדומיין עדיין לא נקבע |
| פלטפורמה | אתר מובייל-קודם + PWA (נימוקים ב-`docs/STACK.md`) |
| אזור השקה | **כל הארץ.** ממלאים בהדרגה בפניות יזומות לעסקים |
| עיצוב | Liquid Glass, בלי אלמנטים שמרגישים "AI" גנרי. header נגלל עם העמוד ולא צף |
| עמוד עסק | סגנון פרופיל פייסבוק. 3 רמות: ברירת מחדל + אישי **בחינם**, PRO בתשלום — מוצג כ"בקרוב" עם רשימת המתנה עד הסליקה |
| PRO (מתוכנן) | ראשונים בחיפוש, תג PRO וטבעת זוהרת, ערכות פרימיום, רקע מתחלף וגלריה בלי הגבלה, באנר מבצעים, קביעת תור, סטטיסטיקות, כתובת אישית |
| סינון תוכן | רשימת מילים גסות בטבלה `banned_terms`, נאכפת בטריגר על עסקים ותמונות |
