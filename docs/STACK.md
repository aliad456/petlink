# החלטת סטאק — PetLink

> תשובה לסעיפים הפתוחים 9.1 (נייטיב / PWA / אתר) ו-9.2 (בחירת סטאק) במסמך האפיון.

## ההמלצה בקצרה

| שכבה | בחירה | למה |
|---|---|---|
| פלטפורמה | **אתר מובייל-קודם + PWA** (אפליקציה נייטיבית בהמשך, אם יהיה צורך) | בסיס קוד אחד, בלי אישורי חנויות, עדכון מיידי, SEO |
| אפליקציה | **Next.js (App Router) + TypeScript** | צד משתמש, צד עסק ופאנל אדמין באותו פרויקט; רינדור בשרת לטובת SEO |
| עיצוב | **Tailwind CSS** | תמיכה מובנית ב-RTL, מהיר לבנייה |
| Backend | **Supabase** (Postgres, Auth, Storage, RLS) | מסד נתונים, התחברות, 2FA ואחסון קבצים מוכנים |
| אירוח | **Vercel** | חינם בהתחלה, פריסה אוטומטית מ-GitHub |
| סליקה | ספק ישראלי עם הוראות קבע: **Cardcom / Grow (משולם) / PayPlus** | יוחלט בשלב 6 |
| AI | **Claude API** | עורך עמודים, ביוגרפיה ומחירון (שלב 7) |

## למה PWA ולא אפליקציה נייטיבית

**יתרונות**
- מפתח אחד, בסיס קוד אחד. אין שתי אפליקציות (iOS/Android) ועוד אתר.
- בלי 99$ לשנה לאפל, בלי תהליכי אישור, ותיקון באג עולה לאוויר תוך דקות.
- **SEO:** אנשים מחפשים בגוגל "וטרינר בחולון שעובד בשבת". עמודי עסק שגוגל יכול לסרוק הם ערוץ ההפצה החינמי הכי חשוב של מדריך.
- כפתורי התקשר / וואטסאפ / ניווט עובדים מצוין בדפדפן (`tel:`, `wa.me`, Waze/Google Maps).
- אפשר להתקין למסך הבית, ובשנים האחרונות גם לקבל התראות Push (כולל iOS מגרסה 16.4).
- המנוי לעסקים נגבה בסליקה רגילה באתר, בלי העמלה של 15%–30% של החנויות.

**חסרונות**
- פחות נראות בחנויות האפליקציות.
- חוויה "פחות אפליקטיבית" במעט, והתראות Push ב-iOS מוגבלות יותר.

**המסלול בהמשך:** אם תהיה דרישה לנוכחות בחנויות, עוטפים את האתר הקיים עם Capacitor. הקוד נשאר אותו קוד.

## למה Supabase

- **Postgres אמיתי**, עם שאילתות מיקום (PostGIS) לחיפוש לפי מרחק, בלי שירות נוסף.
- **Auth מובנה**, כולל אימות דו-שלבי (TOTP), שהאפיון מחייב לכל מנהל.
- **Row Level Security:** ההרשאות נאכפות במסד עצמו. גם אם יש באג בקוד, עובד שירות לקוחות לא יכול למחוק משתמש.
- **Storage** לגלריות, לוגואים ובאנרים.
- **עלות:** חינם בשלב הפיתוח, בערך 25$ לחודש בתוכנית Pro בהשקה.
- **אזור:** לבחור ב-`eu-central-1` (פרנקפורט) — קרוב לישראל, וב-EU לטובת חוק הגנת הפרטיות.

## חלופות שנשקלו

- **Firebase:** מסד NoSQL מקשה על פילטרים משולבים (קטגוריה + מרחק + פתוח עכשיו + מגיע לבית) ועל דוחות לאדמין.
- **React Native / Flutter:** מוסיף אפליקציה שנייה לתחזק, בלי SEO, ועם תלות בחנויות.
- **Bubble וכלי no-code אחרים:** מהיר בהתחלה, אבל RTL, הרשאות מפורטות ויומן פעולות נעשים קשים, ומתקבעים לספק אחד.
